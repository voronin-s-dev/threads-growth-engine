# 💬 1-Click Reactive Commenting Standard

> **Purpose:** Rapid reply generation for incoming viral posts to build early follower momentum.

---

## 1. Speed and Delivery Rules

1. The author responds within 15 to 30 minutes of a post going viral.
2. The agent generates options immediately without multi-step audit loops.
3. Every option must stay under 500 characters.
4. The agent verifies length using character counting before output.
5. The agent presents options in clean, isolated code blocks.

---

## 2. Four Comment Strategies

The agent produces three to four distinct options:
1. **Strategy 1: Contrarian Frame.**
   - Challenges an unexamined assumption with polite, sharp logic.
2. **Strategy 2: Hidden Nuance.**
   - Adds a non-obvious practical exception or edge case from real experience.
3. **Strategy 3: Grounded Personal Case.**
   - Shares a two-sentence real-world result or observation.
4. **Strategy 4: Witty Mirror.**
   - Summarizes the paradox in one punchy, memorable sentence.

---

## 3. Formatting and Inline Micro-Judge

1. The agent marks one option as `(Recommended)`.
2. The agent appends a mandatory one-line micro-judge check under every option:
   - `[Chars: N/500 | Thumb-Stop: X/10 | Tone: Peer / Zero Flattery]`
3. The comment voice remains respectful, confident, and conversational.
4. The author never uses flattery, spam links, or generic agreement ("Great post!").
